个人工作台 - 手机安装使用指南

vivo S30 Pro mini · OriginOS 5 (Android 15) · 6.31英寸 1.5K屏

!
前提条件（请先确认）
  1. 电脑和手机连同一个 WiFi — 这是最关键的一步！手机和电脑必须连接同一个局域网（比如同一个路由器的 WiFi）
  2. 电脑保持开机 — 手机关闭后数据保留在手机本地，但首次安装和以后使用时电脑需要开机并运行服务器
  3. 电脑上服务器已启动 — 我已经帮你启动了，不要关闭那个黑色命令行窗口
注意：如果你的电脑连的是校园网/公司网，手机连的是自己的流量或另一个 WiFi，它们就不在同一个局域网，手机将无法访问。
1
检查并放行防火墙（仅需做一次）

Windows 防火墙可能会阻止手机访问电脑。需要放行 8090 端口：

  1. 在电脑左下角搜索栏输入 「Windows Defender 防火墙」，点击打开
  2. 点击左侧 「高级设置」
  3. 点击左侧 「入站规则」
  4. 点击右侧 「新建规则」
  5. 选择 「端口」，点击下一步
  6. 选择 「TCP」，特定本地端口输入 8090，点击下一步
  7. 选择 「允许连接」，点击下一步
  8. 勾选 「专用」（取消勾选「域」和「公用」），点击下一步
  9. 名称输入 Workbench，点击完成
快捷方法：也可以直接以管理员身份打开 PowerShell，粘贴以下命令一键完成：
New-NetFirewallRule -DisplayName 'Workbench_8090' -Direction Inbound -LocalPort 8090 -Protocol TCP -Action Allow -Profile Private
2
在 vivo 手机浏览器中打开网址

你的 vivo S30 Pro mini 搭载 OriginOS 5（基于 Android 15），系统自带 vivo 浏览器完整支持 PWA 安装。在手机上打开 vivo 浏览器（或 Chrome），在地址栏输入：

http://10.120.92.210:8090

输入后按「前往」或回车键。

如何确认 IP 地址：上面的 10.120.92.210 是你当前电脑的局域网 IP。如果换了 WiFi 网络，IP 可能会变。届时可以在电脑上打开 PowerShell 输入 ipconfig，找到「IPv4 地址」那一行即可。
如果打不开怎么办：
  • 确认手机和电脑连的是同一个 WiFi
  • 确认电脑上那个黑色命令行窗口还在运行（没被关掉）
  • 确认防火墙已放行（步骤1）
  • 如果是校园网，可能需要先登录校园网认证页面
3
首次打开 - 填写个人信息

第一次打开会进入引导页面，需要填写：

  • 昵称 — 你的名字
  • 生日 — 选填
  • 性别 — 选择男/女
  • 身高体重 — 选填，用于计算热量
  • 体质类型 — 点击选择你的中医体质（不确定就选「平和质」）
  • 每日预算 — 默认100元，可修改
  • 其他目标 — 热量、饮水、运动、学习目标，可后续在设置中改

填完后点击底部 「开始使用」 按钮。

提示：所有信息都可以在「设置」页面随时修改，不用担心填错。
4
添加到桌面（安装为 PWA 应用）

方法一：vivo 浏览器（你的 S30 Pro mini 首选）

  1. 用 vivo 浏览器打开网址后，点击底部 「三」（菜单按钮，在底部工具栏右侧）
  2. 在弹出的菜单中找到 「添加到主屏幕」（或先选「收藏/书签」再长按书签选择「添加到主屏幕」）
  3. 确认添加，可以修改名称为「工作台」
  4. 回到手机桌面，会看到一个「工作台」图标，带莫兰迪绿色叶子图标
  5. 点击该图标即可像 APP 一样全屏使用，没有浏览器地址栏，体验和原生 APP 一样
OriginOS 5 优势：你的系统基于 Android 15，PWA 安装后会生成真正的独立应用窗口，支持后台保活、消息通知，体验接近原生 APP。12GB+12GB 运行内存完全不会有性能问题。

方法二：Chrome 浏览器（备选，PWA 体验最佳）

  1. 从应用商店安装 Chrome 浏览器
  2. 用 Chrome 打开网址后，点击右上角 「⋮」（三个点菜单）
  3. 选择 「添加到主屏幕」 或 「安装应用」
  4. Chrome 的 PWA 支持最完善，安装后会出现在「设置 → 应用管理」中，和真正的 APP 一样

方法三：QQ 浏览器

  1. 用 QQ 浏览器打开网址，点击底部 「菜单」
  2. 选择 「添加书签」 → 「添加到主屏幕」
重要：安装到桌面后，每次使用前仍需确保电脑开机且服务器在运行。如果电脑关机了，APP 打开会显示空白或加载失败，这是正常的 — 重新打开电脑和服务器即可恢复。
5
日常使用说明

安装完成后，日常使用流程：

  • 每天使用：直接点桌面图标打开，数据会自动保存在手机本地
  • 底部导航：首页 / 学习 / 护肤 / 饮食 / 财务 / 战略，点击切换
  • 快捷入口：首页有购买顾问、花呗管理、文献、食谱等快捷入口
  • 记录数据：各模块点「+」按钮添加记录，自动保存
  • 智能联动：系统会根据你的财务、运动、护肤状态自动给出饮食建议
离线使用：PWA 安装后，部分页面在手机离线时也能打开（已缓存的页面）。但新增记录需要联网才能同步保存。

常见问题解答
Q: 手机打开后白屏怎么办？
A: 检查电脑是否开机、命令行窗口是否还在运行。如果服务器正常，尝试清除浏览器缓存后重新打开。
Q: 换了 WiFi 后打不开了？
A: 电脑的 IP 地址可能变了。在电脑上打开 PowerShell 输入 ipconfig，找到新的 IPv4 地址，用新地址重新访问。
Q: 数据会丢失吗？
A: 数据保存在手机浏览器的本地存储中。只要不清除浏览器数据，数据就不会丢失。建议偶尔在设置中导出数据备份。
Q: 不想每次都开电脑怎么办？
A: 如果需要永久在线访问，可以将文件部署到免费云服务（如 GitHub Pages、Vercel 等），我可以帮你操作。
Q: 桌面图标怎么删除？
A: 长按桌面图标，选择「卸载」或「移除」，和删除普通 APP 一样。
Q: vivo 浏览器找不到「添加到主屏幕」选项？
A: 部分 vivo 浏览器版本菜单中叫「添加书签」→ 然后在书签管理中长按书签 → 「添加到主屏幕」。也可以安装 Chrome 浏览器使用，Chrome 的 PWA 支持更好。
